# Орыс тілі — электронный учебник

Сайт для уроков русского языка, 2–11 классы: правила, упражнения, чтение, аудирование, диалоги и тесты.

## Как открыть

1. Откройте [главную страницу](./index.html).
2. Выберите класс.
3. Слева откройте модуль и нужный урок.

Локально удобнее запускать через сервер:

```bash
python3 -m http.server 8080
```

Затем откройте `http://localhost:8080`.
