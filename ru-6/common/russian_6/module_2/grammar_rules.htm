Словообразование

Корень слова

Общая часть родственных слов, в которой заключено их основное значение, называется корнем слова.
Слова с одинаковыми корнями называются однокоренными.
МИР → мир
мирный
мирить
примирить
перемирие

Однокоренные слова составляют гнездо. По количеству входящих в него слов оно может быть маленьким и большим.
Так, от слова дрожжи образуется лишь слово дрожжевой, а в гнездо с исходным словом звезда входят слова звёздочка, звёздный, межзвёздный, околозвёздный, созвездие.

Найти корень слова – значит выделить в слове самое главное, понять его смысл.
Есть слова с такими корнями, которые звучат и пишутся одинаково, но имеют разные значения.
Сравните два гнезда слов:
-вод-
водить
вывод
проводник
подводить
приводить		 -вод-
вода
водный
водяной
подводный
подводник

В этих гнёздах разные корни. Такие корни называются омонимичными.

Способы словообразования

В языке постоянно образуются новые слова. В русском языке есть несколько способов образования слов. Важнейшие из них следующие:

Суффиксальный способ

Туман → туман + н + ый → туманный
Туман → туман + н + ость → туманность

белый → белизна (существительное)
белок (существительное)
беляк (существительное)
белеть (глагол)
белить (глагол)
беловатый (прилагательное)
беленький (прилагательное)
бело (наречие)

Приставочный способ

без + звучный → беззвучный
со + звучный → созвучный
ходить → входить
выходить
заходить
уходить
отходить
сходить
переходить
приходить

Приставочно-суффиксальный способ

дорога → подорожник
море → приморский
земля → приземлить

Сложение слов

Сложение слов диван-кровать, ракета-носитель, школа-интернат
Сложение основ с помощью соединительных гласных О и Е лесостепь, луноход, пешеход, сенокос, зверолов
Сложение начальных букв слов.
Слова, образованные этим способом, называются сложносокращёнными.		 МГУ (Московский государственный университет), вуз (высшее учебное заведение), РК (Республика Казахстан)
Сложение начальной части слова с целым словом. стенгазета, драмтеатр, полдыни

Образование слов из словосочетаний

Из подчинительных словосочетаний:
железная дорога → железнодорожный (вокзал)
левый берег → левобережный (район)
белая грудь → белогрудый (птенец)
Из сочинительных словосочетаний:
научный и технический → научно-технический (прогресс)
шахматный и шашечный → шахматно-шашечный (турнир) 
английский и русский → англо-русский (словарь)
Слова, образованные этим способом, называются сложными.
Сложное слово, образованное из подчинительных словосочетаний, пишется слитно: древнерусский (язык) → Древняя Русь.
Сложное слово, образованное из сочинительных словосочетаний, пишется через дефис: электронно-вычислительная (машина) → электронная и вычислительная (машина)

Переход слов из одной части речи в другую

Больной ребёнок уснул. → Больной уснул.
(В первом предложении больной – прилагательное, во втором – существительное).
