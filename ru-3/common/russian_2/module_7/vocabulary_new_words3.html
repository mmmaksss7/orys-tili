Новые слова


Овощи көкөністер
Овощи всегда есть на нашем столе.
Я люблю салаты из овощей.
Огород бақша
В деревне у бабушки большой огород.
Кате нравится работать на огороде.
Грядка атыз, жүйек
Рядом с домом есть грядка с помидорами.
На этой грядке растут огурцы.
Лук пияз
Лук полезен для здоровья.
Мама часто добавляет в пищу лук.
Капуста орамжапырақ, қырыққабат
Капуста растет рядом с домом.
Дария любит пирожки с капустой.
Морковь сәбіз
Морковь – мой любимый овощ.
Кайрат делает салат из моркови.
Огурец қияр
На этой грядке вырос огурец.
На зиму огурцы засаливают.
Помидор қызанақ
У нас вырос большой помидор.
Я делаю салат из помидоров.
